# 报时鸟（DeskBird）第二次团队作业：原型设计 + 概要设计

本目录为团队项目"报时鸟"的第二次作业交付，包含原型设计与概要设计（UML + 数据库）。

## 目录内容

| 文件 / 目录 | 说明 |
| --- | --- |
| `报时鸟_系统设计说明书.pdf` | 系统设计说明书（总体架构、模块、接口、运行与出错处理、UML） |
| `报时鸟_数据库设计说明书.pdf` | 数据库设计说明书（ER 图、关系模型、ORM、约束与索引） |
| `prototype/index.html` | 可交互原型（前台应用 + 后台管理，浏览器打开即可体验） |
| `diagrams/` | UML 图与架构图（用例图、活动图、类图、时序图、协作图、功能结构图、分层架构图、ER 图） |
| `成员产出/` | 七名成员各自的真实工作产出（后端骨架、建表 SQL、测试用例、演示脚本、前后台交互说明、开发计划），由成员本人提交 |
